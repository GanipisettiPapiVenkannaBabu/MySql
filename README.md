\# Online Movie Ticket Booking System



\## Project Overview

This project uses MySQL to manage an online movie ticket booking system.



\## Database Tables

The database contains nine tables:



1\. Admin

2\. Customer

3\. Movie

4\. Theatre

5\. Screen

6\. Seat

7\. Movie\_Show

8\. Booking

9\. Booking\_Seat



\## Main Features

\- Store movie and theatre information.

\- Manage screens and seats.

\- Store movie show schedules.

\- Record customer bookings.

\- Track individual seats assigned to bookings.

\- Generate booking and revenue reports.

\- Validate seat assignments using a MySQL trigger.

\## Setup

1\. Open MySQL Workbench.

2\. Select the project database.

3\. Run the SQL scripts after checking the database name and existing data.

4\. Run the report queries to verify the results.
