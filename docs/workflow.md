\# Online Movie Ticket Booking System — Workflow



\## 1. Database Setup

Create and select the MySQL database.



\## 2. Manage Customers

Store customer details in the Customer table.



\## 3. Manage Movies

Store movie titles, descriptions, and ratings.



\## 4. Manage Theatres and Screens

Store theatre details, screen information, and seat details.



\## 5. Schedule Movie Shows

Connect movies with screens, dates, and showtimes.



\## 6. Book Tickets

Record customer bookings and booking status.



\## 7. Assign Seats

Store individual seats for each booking in Booking\_Seat.



\## 8. Validate Seat Assignments

Use the MySQL trigger to validate that the booking, show, and seat match.



\## 9. Generate Reports

Run SQL queries to view bookings, movie ratings, revenue, and seat assignments.
