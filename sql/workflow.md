\# Online Movie Ticket Booking System — Workflow



1\. Create the MySQL database.

2\. Store customer details in the Customer table.

3\. Store movie details in the Movie table.

4\. Store theatre and screen information.

5\. Create seats for each screen.

6\. Schedule movies using the Movie\_Show table.

7\. Record ticket bookings in the Booking table.

8\. Assign individual seats using the Booking\_Seat table.

9\. Use a trigger to validate seat assignments.

10\. Run SQL queries to view bookings, movie ratings, revenue, and seat assignments.
